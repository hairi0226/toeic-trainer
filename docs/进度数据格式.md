# 进度数据格式（progress.json）

本地 localStorage 的 `tt.progress.v1`、Gist 里的 `progress.json`、设置页导出的文件（外面多包一层 `{app, exported_at, counts, progress}`），都是同一个结构：

```json
{
  "v": 1,
  "attempts": { "<id>": { "id": "...", "q": "day1-q1", "s": "day1", "c": "B", "ok": true, "ms": 12000,
                         "ts": 1757200000000, "m": "practice", "sid": "<会话id>", "qrev": 0, "del": false } },
  "sessions": { "<id>": { "id": "...", "s": "day1", "m": "practice", "src": "online", "start": 0, "end": 0, "ms": 0,
                         "score": 19, "total": 24, "answered": 24, "upd": 0, "label": "Day 1", "wrong": ["day1-q4"],
                         "note": "", "deleted": false } },
  "drafts":   { "<sid>": { "sid": "...", "s": "day1", "m": "exam", "qids": ["day1-q1", "..."], "idx": 3,
                          "answers": { "day1-q1": "B" }, "locked": ["day1-q1"], "spent": { "day1-q1": 8000 },
                          "start": 0, "upd": 0, "label": "Day 1" } },
  "tags":     { "day1-q4": { "cause": "grammar", "ts": 0 } }
}
```

## 字段说明

| 对象 | 字段 | 含义 |
|---|---|---|
| attempt | `q` | 题目 id |
| | `s` | 所属套题 id（快练/错题重做记题目所在套） |
| | `c` | 选的选项字母；纸面录入的"对题"记正确答案、"错题"记 `null`；模考未答记 `null` |
| | `ok` | 是否答对（作答当时按题库答案算好） |
| | `ms` | 本题用时（毫秒，只计前台时间，上限 10 分钟） |
| | `ts` | 作答时间戳；墓碑时会被更新 |
| | `m` | 模式：practice / exam / quick / review / paper |
| | `sid` | 所属会话 id |
| | `qrev` | 作答时题目的修订号；与题库当前 `rev` 不一致的作答不计入统计 |
| | `del` | 墓碑：true = 已撤销 |
| session | `src` | online / paper |
| | `start` / `end` | 开始/结束时间戳；纸面录入的 `start` 是练习日期中午 |
| | `ms` | 总用时（各题 `spent` 之和；纸面为填写的分钟数） |
| | `wrong` | 错题 id 列表 |
| | `upd` | 最后修改时间戳，合并时同 id 取大的 |
| | `deleted` | 墓碑：true = 已删除/已放弃，其名下作答一并忽略 |
| draft | `locked` | 练习模式已作答并锁定的题 |
| | `spent` | 每题累计前台用时 |
| tag | `cause` | vocab / grammar / locate / time；`null` = 删除墓碑 |

## 合并规则（core.js `mergeProgress`）

- 三类记录按 id 取并集；同 id 取时间戳（attempt 用 `ts`，session/draft 用 `upd`，tag 用 `ts`）大的那条。
- 已在 sessions 里有 `end` 的会话，其 draft 一律丢弃（在别的设备完成或放弃了）。
- 因为只做并集，两台设备各自作答再合并不会丢任何一条；删除靠墓碑传播。

## 用命令行读云端进度（给以后的 Claude 会话）

```bash
gh gist list --limit 100 | grep toeic-trainer-progress
gh gist view <gist-id> -f progress.json > progress.json
```

拿到 JSON 后可以直接统计错题、正确率，用来生成下一批针对性练习。
